# Salary Hike Calculator 💼

A simple React-based web application to calculate salary hike percentage and amount.

## 🚀 Features
- Calculate salary hike percentage
- Calculate hike amount
- Displays insight (Low / Average / Strong / Excellent)
- Sends calculation details via EmailJS

## 🛠 Tech Stack
- React (Vite)
- JavaScript
- EmailJS
